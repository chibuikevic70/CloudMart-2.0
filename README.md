# CloudMart 2.0

Enterprise-grade cloud-native e-commerce platform.

## Technology Stack

- AWS
- Terraform
- Docker
- Kubernetes
- Amazon EKS
- Amazon ECR
- PostgreSQL
- Amazon RDS
- Redis
- Amazon ElastiCache
- Amazon S3
- Amazon SQS
- GitHub Actions
- Helm
- Prometheus
- Grafana
- Loki

## Architecture

CloudMart 2.0 is designed as a highly available, containerized,
microservices-based e-commerce platform running on AWS.
